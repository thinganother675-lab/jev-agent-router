# Benchmark harness

The Python scripts here are retained for research and method review. The original raw case sets, labels, result files and fixtures are intentionally excluded because they can contain private prompts or machine-specific data. The aggregate outcomes and limits are in [docs/BENCHMARKS.md](../docs/BENCHMARKS.md).

To run a new evaluation, supply a newly consented case set and keep its labels separate from inference. Review any output path before running: generated JSON and JSONL belong outside Git. The archived local datasets are not a reusable public benchmark.
